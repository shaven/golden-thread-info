# golden-thread-info

The information page for [Golden Thread](https://github.com/shaven/golden-thread), a Claude Code plugin that gives sessions shared memory and enforces rules with hooks.

Live page: https://shaven.github.io/golden-thread-info/

The plugin's source, docs and issues live in the main repo. This repo holds only the page.
